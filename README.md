# KenAI

AI-powered home repair assistant. Uses Claude to help diagnose issues and guide homeowners through fixes.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Environment Variables

Create a `.env.local` file:

```
ANTHROPIC_API_KEY=<your-key>
```

## Deployment

Pushes to `dev` auto-deploy to production via Vercel.
Pull requests get preview URLs automatically.
